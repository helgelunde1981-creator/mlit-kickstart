# Brutalism Refined

> Rå struktur, intensjonell kontrast, hover-kunst. Brutalism uten å være lesefiendlig — bevisst kjedede skrifter, bold farge-blokker, asymmetri som kommentar.

## Use når

- Tech-startups med personality
- Kreative byråer
- Kultur, musikk, kunst
- Web3 / alt-tech med trygg avantgarde-bias

## Ikke bruk når

- Trygge bransjer (finans, juridisk, helse)
- B2B SaaS for konservative kunder
- E-handel som krever trust-signals

## Signaturmoves

- **Monospace headlines** — store og dristige
- **Primær-farge i blokker** — solid backgrounds, ikke gradient
- **Harde shadows** — 4px solid offset, ikke blur
- **Hover-states som "snapper"** i posisjon — translateX(4px) + shadow
- **Borders 2-3px svart** der det passer
- **Asymmetri som kommentar** — bevisst skjev layout
- **Heavy keyboard-feel** — sans-serif fonts med character
