# Editorial Bento

> Asymmetriske grids, store typografi-moments, magazine-feel. Bento-blokker av varierende størrelser med klar visuell hierarki.

## Use når

- Media, blogg, portefølje
- Agency-sider med caser
- Produkt-launch med flere features
- Personlig site / portfolio

## Ikke bruk når

- Single-purpose landing page (signup, app download)
- Komplekse dashboards med data-tetthet
- Konservative bransjer (juridisk)

## Signaturmoves

- **Asymmetrisk bento-grid** — celler av 1×1, 2×1, 1×2, 2×2 størrelser
- **Store quote-blokker** med over-the-top typografi
- **Sticky scroll-elementer** i sidebar-aktige posisjoner
- **Magazine-style nummerering** av seksjoner ("01 / 06")
- **Klare seksjons-skiller** med horizontal rules og headings
- **Editorial mix** av bilde + tekst + interaktivt

- `tokens.css`
