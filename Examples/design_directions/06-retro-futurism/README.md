# Retro-Futurism

> VHS/CRT-elementer, neon, monospace, scanlines. Y2K-revival med moderne build-kvalitet.

## Use når

- Gaming, musikk, alt-tech
- Web3 med æstetisk personlighet
- Kulturprosjekter (festivals, label-sites)
- Brands som vil signalisere "nostalgia + innovation"

## Ikke bruk når

- Trygge bransjer (finans, helse, juridisk)
- Ikke-tech B2B
- Når enterprise-kunder er målet

## Signaturmoves

- **Chromatic aberration** — subtle RGB-shift på hover/scroll
- **Scanline-overlays** — animert horizontal scan-effekt
- **Neon-glow** — accent-farger med blur-shadow
- **Monospace UI** — alt fra navigasjon til CTA
- **Retro grids** — 80s computer-grafikk grids
- **Crt-effekt** subtilt — vignet, scanlines, fosfor-glød
