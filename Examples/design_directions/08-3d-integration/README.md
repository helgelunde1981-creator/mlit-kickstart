# 3D Integration

> Three.js/Spline integrert i kjerneopplevelsen. Ikke gimmick — bygger forståelse av produktet.

## Use når

- Produkt-launch (hardware, physical product)
- Hardware-merker
- Immersive brand-opplevelser
- Tech med produkter du kan rotere/utforske
- High-end edukasjon (anatomi, fysikk)

## Ikke bruk når

- Performance er ekstra kritisk (mobile-first med lav-end)
- Content-tunge sites
- Budsjett er begrenset (3D-arbeid koster)
- Når produktet ikke har visuell form

## Signaturmoves

- **Roterende produkt-modeller** — hovedforside-fokus
- **Scroll-styrt kamera** — sees produktet fra ulike vinkler ved scroll
- **GPU-akselererte transitions** — ikke layout reflows
- **Fallback til static-render** for low-end devices (poster.jpg)
- **Spline for ikke-tekniske 3D** — drag-and-drop builder
- **Three.js for custom** — kompleks geometri, shaders
