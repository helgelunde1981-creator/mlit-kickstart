# Industrial / Robust

> Matt, taktil, no-nonsense. For B2B/transport/anlegg/entreprenør der "premium luxury" føles feil. Inspirert av godt industri-design — funksjonalitet først, men ikke kjedelig.

## Use når

- B2B-tjenester (anlegg, transport, bygg, industri)
- Entreprenør og håndverk
- Tungtekniske produkter
- "Pålitelig partner"-posisjonering
- Lagre, logistikk, supplies

## Ikke bruk når

- Premium B2C
- Kreative bransjer
- Når brand-personlighet er det viktigste

## Signaturmoves

- **Materielle teksturer** — concrete, metal, paper-grain
- **Monospace til tall** — vekter, mål, datoer, ID-nummer
- **Harde rutenett** — som industri-tegninger
- **Høyt informasjons-tetthet** — tabeller, data, spec-sheets
- **Knapper som ser ut som de tåler en støvete hånd** — solid, lett over-built
- **Industri-fargepalett** — safety-orange, matte greys, signal-blå
- **Klare hierarkier** — ikke subtilt, ikke playful
