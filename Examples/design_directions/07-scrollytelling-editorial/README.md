# Scrollytelling Editorial

> Narrativ scroll, sticky stages, progressive reveal. Innholdet er fortellingen — scroll er hvordan vi forteller den.

## Use når

- Long-form innhold (kampanjer, dokumentarer)
- Produkt-launch som krever forklaring
- Data-storytelling
- Brand-historie

## Ikke bruk når

- Funksjonelle apps (dashboard, admin)
- Sider folk skal gjøre raske oppgaver på
- Mobile-first der scroll-effekter brytes lett

## Signaturmoves

- **Sticky containers** med sequenced reveals
- **Parallax** brukt sparsomt — kun der det støtter narrativet
- **Scroll-progress-indikator** øverst eller siden
- **Fading transitions** mellom stages
- **Pinned visualizations** som endres mens tekst scroller
- **Snap-points** for å tvinge stops på nøkkelstages
