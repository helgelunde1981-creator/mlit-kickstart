# Signature Moments — Eksempler

> Et signature moment er produktets fingeravtrykk. Det er det brukeren husker etter besøket. Hver `PROJECT.md` (§5) MÅ ha minst ett.

Disse eksemplene fungerer som referanse for AI når den genererer signature moment-seksjoner. Hver fil følger samme 5-punkts-struktur som `00-SYSTEM_PROMPT.md` krever.

## Eksempler i denne mappen

1. **`budogvare-live-calculator.md`** — Live fraktkalkulator med real-time pris-breakdown
2. **`scroll-product-tour.md`** — Scroll-triggered product walk-through med pinned visualization
3. **`interactive-pricing-grid.md`** — Bento-grid der hver celle er en interaktiv pris-konfigurator
4. **`ambient-data-visualization.md`** — Hero-area som viser live data fra produktet (uptime, transactions, etc.)
5. **`signature-onboarding-moment.md`** — Engaging first-run experience som setter tonen

## Felles struktur per fil

Hver signature moment-eksempel skal ha:

1. **Hva** — én setning beskrivelse
2. **Hvor** — URL og posisjon
3. **Oppførsel** — alle states, transitions, edge cases
4. **Hvorfor signature** — hvorfor representerer dette produktet
5. **Suksessmetrikk** — hvordan måler vi at det fungerer

## Hvordan AI bruker disse

Når AI genererer §5 av en ny `PROJECT.md`:

1. Sjekk om kundeprosjektet har et "naturlig" signature moment kandidat (kalkulator? interaktiv kart? real-time data?)
2. Velg den nærmeste fra disse eksemplene som mønstergyldig
3. Tilpass strukturen til kundens kontekst
4. Sørg for at alle 5 punkter er konkrete, ikke vage
